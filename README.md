# Bike Sales Analysis & Dashboard (Excel)

## Project Overview
This project analyzes bike buyer data using Microsoft Excel to explore customer demographics and bike purchasing patterns.

## Objectives
- Analyze bike purchases across customer segments.
- Explore the relationship between income and bike purchasing.
- Examine purchasing patterns by age, gender, occupation, and commute distance.
- Present findings using PivotTables, PivotCharts, and an Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Data Analysis and Visualization

## Workbook Structure

| Sheet | Description |
|---|---|
| Bike Buyers | Contains the original bike buyer dataset. |
| Pivot Table | Summarizes the data for analysis. |
| Dashboard | Presents the analysis visually. |

## Key Analysis Areas
- Bike purchases by gender and income.
- Customer demographics and purchasing patterns.
- Bike purchases across different age groups.
- Purchasing patterns by occupation and commute distance.

## Project Outcome
Developed an Excel-based analysis and dashboard to summarize bike buyer characteristics and explore purchasing patterns.
